## 3. Third-party components and distribution conditions

GOO Web Server is an installer. Except for the explicitly bundled files listed below, it obtains web-server, PHP, and database packages from their official distribution channels during installation. The installed versions and their accompanying license files control.

| PHP / PHP-FPM | Installed from approved Ubuntu/PHP package sources | PHP License 3.01 for the selected PHP 8.3–8.5 series, subject to upstream package notices | It is not bundled; the selected package's terms apply. |
| MySQL Community Server 8.4 LTS | Optionally installed from Oracle's official APT source | GPLv2 and the exact MySQL Community release notices/exceptions | It is not bundled. Do not embed or redistribute MySQL binaries under this project license. |
| PostgreSQL 17 | Optionally installed from the official PGDG source | PostgreSQL License | It is not bundled; the selected package's terms apply. |
| Microsoft Drivers for PHP for SQL Server (`sqlsrv`, `pdo_sqlsrv`) | Optional NTS PHP extension assets | MIT License for the Microsoft driver project | Include the matching MIT license and attribution with any bundled driver binary. |
| Microsoft ODBC Driver 18 for SQL Server | Downloaded from Microsoft's repository only when SQLSRV is selected | Microsoft EULA | It is not bundled. Installation requires an explicit `--accept-microsoft-eula` acknowledgement. |
| ionCube Loader | Bundled optional PHP loader asset | ionCube Loader EULA | Do not relicense or rebrand it. Every release containing Loader binaries must include the exact ionCube Loader EULA. |

### Required release gate

Before publishing a GOO Web Server `.deb` that contains `ioncube_loader_*`, `sqlsrv`, or `pdo_sqlsrv` binaries, the release maintainer must verify all of the following:

1. The binary came from an authorized upstream source and matches the selected PHP ABI, platform, architecture and NTS/ZTS mode.
2. The binary's SHA-256 manifest is included and verified by the installer.
3. The exact applicable ionCube Loader EULA and Microsoft driver MIT license are appended to this single `LICENSE` file without modification.
4. No customer license, private signing key, access token, activation secret, or confidential material is included in the repository or release asset.

The current source tree contains placeholders for the first two checks. **A public binary release containing ionCube or SQLSRV assets must not be published until the corresponding authoritative upstream license texts have been appended to this document.**
